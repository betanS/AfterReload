# AfterReload - Guía de Migración de Servidores (Wings & CS2)

Este documento detalla cómo levantar la infraestructura de servidores de juego.

## 1. Instalación de Wings (Daemon)
1. **Descargar Binario:**
   ```bash
   sudo curl -L -o /usr/local/bin/wings "https://github.com/pterodactyl/wings/releases/latest/download/wings_linux_amd64"
   sudo chmod +x /usr/local/bin/wings
   ```
2. **Configuración:** El archivo debe estar en `/etc/pterodactyl/config.yml` (o tu ruta personalizada `/var/www/afterreload/.wings/etc/config.yml`).
3. **Servicio Systemd:** (Ver el archivo creado anteriormente o usar `sudo systemctl enable --now wings`).

## 2. Migración de Servidores Existentes
Si vas a mover los servidores de la carpeta `csgoserver` a Pterodactyl:
1. **Crear el servidor en el Panel** de Pterodactyl.
2. **Identificar el UUID** del servidor creado.
3. **Mover archivos:**
   ```bash
   cp -r /var/www/afterreload/csgoserver/serverfiles/* /var/lib/pterodactyl/volumes/<UUID>/
   ```
4. **Ajustar Permisos:**
   ```bash
   chown -R pterodactyl:pterodactyl /var/lib/pterodactyl/volumes/<UUID>/
   ```

## 3. Puertos y Firewall
Asegúrate de abrir los siguientes puertos en el servidor:
- **8080 (TCP):** API de Wings.
- **2022 (TCP):** SFTP de Wings.
- **27015-27020 (UDP/TCP):** Puertos de juego CS2/CSGO.
- **80/443 (TCP):** Web y Proxy de Wings.

## 4. Configuración de Nginx para el Nodo (SSL)
Para que el panel pueda hablar con Wings sin errores de seguridad:
```nginx
server {
    listen 443 ssl;
    server_name node1.afterreload.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
