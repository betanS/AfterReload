# Documentación Técnica: AfterReload

## 1. Requisitos del Sistema
- **PHP**: 8.3 (Extensiones: bcmath, ctype, fileinfo, json, mbstring, openssl, pdo, tokenizer, xml)
- **Servicios**: Nginx, Redis, MySQL/SQLite
- **Dependencias OS**: lib32gcc-s1, lib32stdc++6 (CS:GO Legacy)

## 2. Configuración y Automatización
Cron para tareas de limpieza y gestión (Usuario: `csgoserver`):
`* * * * * cd /var/www/afterreload && php artisan schedule:run >> /dev/null 2>&1`

## 3. Lógica de Lobbies y Servidores
- **Públicos**: Gestión de slots dinámicos con salida automática vía JS.
- **MM**: Matchmaking vía Get5 con limpieza automatizada en Admin.
- **Seguridad**: RCON para comandos remotos vía `RconClient`.

## 7. IMPLEMENTACIÓN

### Estructura de directorios
- `app/`: Lógica de negocio (Services, Http, Models).
- `config/`: Configuraciones del sistema.
- `database/`: Migraciones y seeders.
- `resources/`: Vistas (Blade), CSS/JS.
- `routes/`: Definición de endpoints web y API.
- `csgoserver/`: Entorno de ejecución LinuxGSM.

### Descripción de ficheros
- `Server.php`: Modelo de gestión de servidores.
- `LobbyController.php`: Lógica de gestión de slots y equipos.
- `AdminController.php`: Panel de control de servidores y limpieza.
- `RconClient.php`: Cliente para ejecución de comandos remotos en juegos.

## 8. VALIDACIÓN Y PRUEBAS

### Herramientas
- **PHPUnit**: Framework para tests automatizados.
- **Tinker**: Consola interactiva para depuración de DB en tiempo real.
- **Consola del Navegador (F12)**: Para depuración de lobbies (Network/Console).

### Ejecución
- Tests: `php artisan test`
- Limpieza manual: Utilizar Dashboard Admin ("Limpiar MM" / "Limpiar Públicos").

## 9. RESULTADOS

### Conclusiones
- Se logró una gestión robusta de servidores CS:GO sin dependencias externas (Pterodactyl).
- El sistema de lobbies dinámicos elimina la persistencia de "jugadores fantasma".
- La centralización en el Panel Admin permite un mantenimiento rápido ante bloqueos.

### Trabajos futuros
- Implementación de un sistema de logs remoto para comandos RCON.
- Refinamiento de la UI del dashboard con gráficos de uso en tiempo real.
- Migración de las configuraciones de los servidores a un sistema de base de datos relacional.
