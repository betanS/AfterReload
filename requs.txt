# AfterReload - Guía Maestra de Migración y Optimización (Web)

Este documento contiene todo lo necesario para levantar la web de AfterReload desde cero en un nuevo servidor con el máximo rendimiento.

## 1. Requisitos del Sistema
- **SO:** Ubuntu 22.04 LTS o superior.
- **PHP 8.3:** Extensiones: `dom`, `curl`, `mbstring`, `zip`, `pcntl`, `bcmath`, `intl`, `gd`, `redis`.
- **Base de Datos:** MariaDB 10.11+.
- **Caché & Queue:** Redis Server (Obligatorio para Lobbies y rendimiento).
- **Node.js 24 LTS & NPM.**

## 2. Instalación y Permisos
```bash
git clone https://github.com/betanS/AfterReload.git
chown -R www-data:www-data storage bootstrap/cache
chmod -R 775 storage bootstrap/cache
composer install --optimize-autoloader --no-dev
npm install && npm run build
php artisan migrate --force
```

## 3. Procesos de Fondo (Vital para Funcionalidad)

### A. Supervisor (Queues)
Configura los workers para que los servidores se sincronicen al instante.
Archivo: `/etc/supervisor/conf.d/afterreload-worker.conf`
```ini
[program:afterreload-worker]
command=php /var/www/afterreload/artisan queue:work --sleep=3 --tries=3
autostart=true
autorestart=true
user=www-data
numprocs=2
```

### B. Crontab (Tareas Programadas)
```bash
* * * * * cd /var/www/afterreload && php artisan schedule:run >> /dev/null 2>&1
```

## 4. Optimización de Producción (.env)
Para que la web cargue en <100ms:
- `APP_DEBUG=false`
- `APP_ENV=production`
- `CACHE_STORE=redis`
- `SESSION_DRIVER=redis`
- `QUEUE_CONNECTION=redis`

## 5. Configuración Nginx (SSL)
```nginx
server {
    listen 443 ssl http2;
    server_name afterreload.com;
    root /var/www/afterreload/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_buffering on;
    }
}
```
