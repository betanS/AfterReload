# AfterReload - Guía Maestra de Migración (Web)

Este documento contiene todo lo necesario para levantar la web de AfterReload desde cero en un nuevo servidor.

## 1. Requisitos del Sistema
- **SO:** Ubuntu 22.04 LTS o superior.
- **PHP 8.3:** Con extensiones: `dom`, `curl`, `libxml`, `mbstring`, `zip`, `pcntl`, `bcmath`, `soap`, `intl`, `gd`, `redis`.
- **Base de Datos:** MariaDB 10.11+.
- **Caché:** Redis Server (Crucial para Lobbies).
- **Node.js 24 LTS & NPM.**

## 2. Instalación Paso a Paso
1. **Clonar y Permisos:**
   ```bash
   git clone https://github.com/betanS/AfterReload.git
   chown -R www-data:www-data storage bootstrap/cache
   chmod -R 775 storage bootstrap/cache
   ```
2. **Dependencias:**
   ```bash
   composer install --optimize-autoloader --no-dev
   npm install && npm run build
   ```
3. **Variables de Entorno (.env):** Asegurar que estas coincidan:
   - `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`.
   - `STEAM_CLIENT_ID`, `STEAM_CLIENT_SECRET`, `STEAM_REDIRECT_URI`.
   - `PTERODACTYL_HOST`, `PTERODACTYL_CLIENT_API_KEY`.
4. **Base de Datos:**
   ```bash
   php artisan migrate --force
   ```

## 3. Configuración de Nginx (SSL Obligatorio)
```nginx
server {
    listen 443 ssl;
    server_name afterreload.com;
    root /var/www/afterreload/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }
}
```
